# Vector Stores & Search
# faiss-gpu (not faiss-cpu): the retrieval path embeds on the GPU, and a CPU-only
# FAISS build cannot accept those tensors. With faiss-cpu installed,
# faiss.StandardGpuResources does not exist, so the store silently fell back to a
# CPU index and every search paid a blocking device-to-host copy of the query.
# The -cu12 build matches the CUDA 12.x runtime that torch 2.5.1 links against.

# CPU fallback for environments without a GPU wheel available. Install this INSTEAD
# of faiss-gpu-cu12 and set FAISS_REQUIRE_GPU=false to run retrieval on CPU.
